3.6.2 页式虚拟存储器

1.页表 

1.1 有效位（装入位）： 对应虚页是否存在主存，1 是

1.2 脏位（修改位）：决定是否页面是否被修改，决定是否回写磁盘

1.3 引用位 (使用位) ：记录页面访问，可实现基于页面访问的页面置换算法（clock /RLU）

2.地址转换

高位虚页号低位页内偏移

**分页转换（最常用）**

设页大小为 \(S\)，虚拟地址为 \(VA\)：

[
\\text{页内偏移 } d = VA \\bmod S
]

[
\\text{虚拟页号 } VPN = \\lfloor VA / S \\rfloor
]

查页表：

[
PTE = PageTable[VPN] \\rightarrow PFN
]

物理地址：

[
PA = PFN \\times S + d
]

若页大小 \(S=2^k\)，用位运算更简明：

[
d = VA \\ \\&\\ (S-1)
]

[
VPN = VA \\gg k
]

[
PA = (PFN \\ll k) \\ | \\ d
]

**核心：页内偏移不变，虚拟页号查表换成物理页号。**

---

**多级页表**

虚拟地址拆成：

[
VA = [L*1][L*2]\\cdots[L\_n][d]
]

逐级查表：

[
L*i = (VA \\gg shift*i) \\ \\&\\ mask\_i
]

最后得到物理页号 \(PFN\)：

[
PA = (PFN \\ll k) \\ | \\ d
]

---

**分段**

虚拟地址 = 段号 + 段内偏移：

[
VA = (s, d)
]

查段表得基址 \(base\) 和限长 \(limit\)：

[
d < limit \\Rightarrow PA = base + d
]

否则越界异常。

---

**段页式**

虚拟地址：

[
VA = (段号,\\ 页号,\\ 页内偏移)
]

先查段表得到页表基址，再查页表得到物理页号：

[
PA = PFN \\times S + 页内偏移
]

即：

[ PA = (PFN ll k)  |  d]

转换时需检查页表项有效位、权限；缺页则触发缺页异常，TLB 命中可直接得到 \(PFN\)。
